<p align="center">Element Plus - 基于 Vue 3 的组件库</p>

- 💪 Vue 3 Composition API
- 🔥 使用 TypeScript 编写

## 快速开始

如果你希望帮助 Element Plus 变得更好，请继续阅读。
如果你是使用 Element Plus 构建网站的开发者，请访问 [快速开始](https://element-plus.org/zh-CN/)。

- 中国大陆[加速镜像站点](https://cn.element-plus.org/zh-CN/)

## 破坏性变更列表

Element Plus 的首个可用于生产环境的稳定版本已于 2022 年 2 月 7 日发布。现在 API 已经稳定，我们整理了一份从 [Element UI](https://element.eleme.io) 升级到 Element Plus 的完整说明。

你可以在这里查看： [破坏性变更列表](https://github.com/element-plus/element-plus/discussions/5658)。

### 迁移工具 :hammer_and_wrench:

我们为你准备了从 [Element UI](https://element.eleme.io) 迁移到 Element Plus 的工具。

你可以在这里找到 [gogocode 迁移工具](https://github.com/thx/gogocode/tree/main/packages/gogocode-plugin-element)。

我们已使用 [Vue Element Admin](https://github.com/PanJiaChen/vue-element-admin) 对其进行了测试。你可以在 [这里](https://github.com/gogocodeio/vue-element-admin) 查看转换后的代码。

## 翻译

Element Plus 已被翻译成多种语言。你可以点击 [这里](https://crowdin.com/project/element-plus) 帮助我们更新翻译，或申请成为校对人员。

由于资源有限，我们目前仅提供英文和中文版本，但也期待将其翻译成更多语言。如果你愿意帮助 Element Plus 翻译成你偏好的语言，请访问上面的链接并留言。

### 如何协助翻译

请参阅 [翻译 Element Plus](https://element-plus.org/zh-CN/guide/translation.html)，了解如何参与翻译。
